# 유콜 데스크

📣 유콜(YOUcall) — 교무실에서 학생을 부르면 교실 화면에 뜨는 호출 시스템의 **윈도우 설치형 클라이언트**입니다.
브라우저를 항상 띄워두지 않아도, 호출이 오면 자동으로 창이 뜨고 평소에는 시간표·급식·학사일정을 보여주는 홈스크린으로 동작합니다.

> 💡 **설치는 선택 사항입니다.** 지금처럼 브라우저로 접속해서 쓰셔도 모든 기능이 똑같이 동작합니다.
> 💡 전자칠판 **자체가 안드로이드**라면(전원을 켜면 앱 아이콘 화면이 뜬다면) 이 exe는 설치되지 않습니다.
> 대신 [유콜 보드(Android APK)](https://github.com/kimju1416/youcall-board/releases/latest)를 쓰세요.

## 다운로드

[Releases](https://github.com/kimju1416/youcall-desktop/releases/latest)에서 `YouCallDesk-Setup.exe`를 내려받아 실행하세요. 별도 확인창 없이 바로 설치됩니다.

> ⚠️ 설치할 때 윈도우 보안 경고(SmartScreen)가 뜨면 **「추가 정보」 ▸ 「실행」**을 누르세요.

## 특징

- 창 크기조절·최소화 가능 (전체화면 강제 아님 — 바탕화면 아이콘을 가리지 않음)
- 닫기(X)를 눌러도 완전 종료되지 않고 트레이로 숨겨져 계속 대기
- 새 호출이 오면 창 자동 복원 또는 토스트 알림만 — 설정에서 선택 가능
- 상시 대기화면(시간표·급식·학사일정) 표시 여부도 설정에서 켜고 끌 수 있음
- 윈도우 시작 시 자동 실행 지원
- 학교마다 자신의 유콜 웹앱 URL + 학년/반만 입력하면 바로 사용 가능 (배포용)

## 최초 실행

1. 설치 후 실행하면 설정 화면이 뜹니다.
2. 우리 학교 유콜 웹앱 URL, 학년, 반을 입력합니다.
3. 저장하면 바로 대기화면이 표시됩니다.

### 웹앱 URL은 어디서 구하나요?

평소 유콜을 열던 주소입니다. 주소 뒤에 `?role=teacher` 가 붙어 있으면 그 부분은 빼고 `.../exec` 까지만 입력하세요.
모르겠다면 교무실 PC에서 유콜 스프레드시트 ▸ **확장 프로그램 ▸ Apps Script ▸ 배포 ▸ 배포 관리**에서 확인할 수 있습니다.

## 자주 묻는 질문

**호출이 2~3초 뒤에 떠요.**
정상입니다. 구글 서버를 거쳐 오는 구조라 2~3초 정도 걸립니다. 앱이든 웹이든 동일합니다.

**교실마다 다르게 써도 되나요?**
됩니다. 1반은 웹, 2반은 exe로 써도 서로 아무 영향이 없습니다.

**앱을 깔면 교무실 PC도 바꿔야 하나요?**
아니요. 교사용은 지금처럼 웹(주소 뒤 `?role=teacher`) 그대로 쓰시면 됩니다.

**시트를 새로 사본 뜨면?**
주소가 바뀌므로, 설정 화면에서 새 주소로 바꿔주세요.
