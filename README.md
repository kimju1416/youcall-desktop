# 유콜 데스크

📣 [유콜(YOUcall)](https://github.com/kimju1416/ssam-zip) 전자칠판/교실 화면 전용 설치형 클라이언트입니다.
브라우저를 항상 띄워두지 않아도, 호출이 오면 자동으로 창이 뜨고 평소에는 시간표·급식·학사일정을 보여주는 홈스크린으로 동작합니다.

## 다운로드

[Releases](https://github.com/kimju1416/youcall-desktop/releases/latest)에서 최신 `유콜데스크-Setup-X.X.X.exe`를 내려받아 설치하세요.

## 특징

- 창 크기조절·최소화 가능 (전체화면 강제 아님 — 바탕화면 아이콘을 가리지 않음)
- 닫기(X)를 눌러도 완전 종료되지 않고 트레이로 숨겨져 계속 대기
- 새 호출이 오면 창 자동 복원 또는 토스트 알림만 — 설정에서 선택 가능
- 상시 대기화면(시간표·급식·학사일정) 표시 여부도 설정에서 켜고 끌 수 있음
- 윈도우 시작 시 자동 실행 지원
- 학교마다 자신의 유콜 웹앱 URL + 학년/반만 입력하면 바로 사용 가능 (배포용)

## 최초 실행

1. 설치 후 실행하면 설정 화면이 뜹니다.
2. 우리 학교 유콜 웹앱 URL, 학년, 반을 입력합니다.
3. 저장하면 바로 대기화면이 표시됩니다.

## 개발

```
npm install
npm start          # 개발 실행
npm run build:win  # exe 빌드 (electron-builder)
```
